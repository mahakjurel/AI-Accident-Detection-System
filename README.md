# AI-Accident-Detection-System
AI-based real-time accident detection and emergency alert system
An AI-powered system that detects road accidents from video input and sends instant emergency alerts to reduce response time and save lives.

🔹 Key Features

Live camera monitoring

Video upload for accident detection

AI-based accident classification

Emergency alert system (ambulance, police, contacts)

Admin dashboard for accident records

Frontend–backend REST API integration

🔹 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Python, FastAPI

AI/ML: TensorFlow, OpenCV

Database: SQLite

🔹 How to Run

Backend

cd backend
python main.py


Frontend

cd frontend
python -m http.server 5500


Open: http://localhost:5500

🔹 Project Use Case

This system helps in early accident detection and quick emergency response, which can significantly reduce fatalities caused by delayed medical assistance.
